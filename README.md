# 高中物理 · 电路可视化实验室

一个**单文件、零依赖**的高中物理电学交互仿真程序：`电路可视化-演示-v0.6.html`。
双击即可在浏览器中打开（支持 `file://`），无需安装任何环境，离线可用。

## 功能一览

### 元件库（GB/T 4728 符号规范）
| 元件 | 说明 |
|---|---|
| 电池 | 含内阻，电动势可调 |
| 定值电阻 / 电阻箱 | 电阻箱整数步进 0–9999 Ω，可读数 |
| 小灯泡 | 亮度随实际功率变化，超额定功率告警 |
| 开关 / 单刀双掷开关 | 单击切换通断 / 选通 A、B 支路 |
| 滑动变阻器 | 三端模型，限流 / 分压 / 定值三种接法，滑片可拖 |
| 电流表 / 电压表 | 表盘实时读数 |
| 灵敏电流计 | 零点居中指针随电流方向偏转，超满偏告警 |
| 电动机 | 非纯电阻：UI = I²R + EI，含启动/发电工况 |
| 电容器 | 直流稳态：隔直流，显示 Q = CU 与储能 |
| 导线节点 | 四向纯连接点，布线规整 |

### 仿真内核
- 节点电压法（MNA）+ LU 分解求解，导线按 1 mΩ 建模，电流动画沿导线流动
- 所有读数均经**手算校验**（串联 0.182 A / 并联 0.418 A / 分压 0.2105 A / 电桥平衡等）

### 教学辅助
- 数据表：逐元件 U / I / P；变阻器分 A-P、P-B 两段显示
- 诊断：电源短路、断路、灯泡超功率、灵敏电流计超满偏、电容隔直流提示
- 7 个内置示例：串联 / 并联 / 分压 / 切换 / 电动机 / 惠斯通电桥 / 电容
- 惠斯通电桥可现场演示"调平衡 → 灵敏电流计读零"

### 编辑器
- 撤销 / 重做（Ctrl+Z / Ctrl+Y，100 步）、保存 / 加载 JSON、本地恢复
- 视图缩放（按钮 / 滚轮）与平移（空白处拖动）

## 使用方法

1. 下载 `电路可视化-演示-v0.6.html`，双击打开即可；
2. 从左侧元件库拖元件到画布，点元件引脚拉线到另一引脚连线；
3. 点导线可选中删除，右上角按钮保存 / 加载电路文件。
