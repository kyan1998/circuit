# 高中物理 · 电路可视化实验室

一个**单文件、零依赖**的高中物理电学交互仿真程序：`电路可视化-演示-v1.13.html`。

> 本地定制（2026-11-27）：示波器增加纵轴数值刻度；模板库改为用户自定义的 7 个内置模板（可在管理模式隐藏/恢复；启动串联示例不进模板库）。
双击即可在浏览器中打开（支持 `file://`），无需安装任何环境，离线可用。

## 功能一览

### 元件库（27 种，符号遵循 GB/T 4728；v1.9 起折叠为窄条分类栏，点击向右展开）

| 类别 | 元件 | 要点 |
|---|---|---|
| 电源 | 电池、交流电源 | 电池含内阻；交流源峰值/频率/内阻可调（v1.3 修复内阻未接入的问题），面板含 RLC 谐振分析块 |
| 电阻类 | 定值电阻、电阻箱、金属丝 | 电阻箱整数步进 0–9999Ω；金属丝按材料/长度/直径实时算 R=ρL/S |
| 负载 | 小灯泡、电动机 | 灯泡亮度随功率、超额定告警；电动机反电动势模型（UI = I²R + EI） |
| 开关 | 单刀单掷、单刀双掷、双刀双掷 | 单击切换；单/双刀联动换向 |
| 调节 | 滑动变阻器 | 三端模型，限流 / 分压 / 定值三种接法，滑片可拖 |
| 电表 | 电流表、电压表、灵敏电流计、理想电流表、理想电压表 | 灵敏电流计零点居中指针、超满偏告警；理想表真理想（0V 源支路 / 零 loading，见 v1.1） |
| 半导体 | 二极管、LED | 分段线性模型，单向导电，反接截止提示，LED 通电发光 |
| 储能 | 电容器、电感线圈 | 电容稳态隔直流 + 暂态充放电；电感暂态自感、续流 |
| 传感器 | 热敏电阻、光敏电阻 | NTC 公式 / 光照幂律，滑杆交互 |
| 控制 | 电磁继电器 | 线圈电流达吸合值→触点动作（com→no / com→nc） |
| 连接 | 导线、导线节点（十字 / T形 / L形 / 一字，后三种可旋转换朝向） | 导线按 1µΩ 建模（电流动画沿导线流动；v1.9 由 1mΩ 下调，读数与手算一致）；四向节点规整布线 |

### 仿真内核
- 节点电压法（MNA）+ LU 分解（列主元），导线按 1 µΩ 建模（仅为电流动画保留可算电流，v1.9 由 1 mΩ 下调，读数与手算一致）
- **时间轴引擎（v1.0 引入，v1.3 改梯形积分）**：电容/电感用梯形积分伴随模型（无损、二阶精度，SPICE 同款）——旧后向欧拉会引入 dt/(2C) 与 Lω²dt/2 的数值串联电阻，在低阻 RLC 回路里误差高达 40%
- 二极管与继电器的非线性状态整网迭代收敛
- 所有读数均经**手算校验**（串联 0.182 A / 并联 0.4186 A / 电桥平衡 / RLC 谐振电流 −0.04% / 充放电指数曲线 / RC 相位滞后等）

### 时间轴仿真、示波器与 RLC 谐振（「▶ 暂态仿真」按钮）
- **电感线圈**：通电自感（电流缓慢上升）、断电续流（电流经并联支路反向衰减）
- **交流电源**：峰值/频率/内阻可调的正弦源，观察 RC 电路的相位滞后
- **示波器（v1.4 扫描模式）**：光点从左向右画出波形（教材/真实示波器习惯），画满一屏回左边重画，上一屏淡显残像；有交流源时每屏对齐到整数个周期（触发），波形稳定不漂移；时基可选（自动 / 50ms–3s）；逐仿真步采样（常速约 2000 点/秒，50Hz 也能画出清晰正弦）；保留原滚动模式可切换
- **扫频分析（v1.3）**：对示波器当前选中信号在 f₁→f₂ 区间逐频点实测稳态幅值，绘制幅频曲线并标注理论谐振频率 f₀ 与实测峰（约 2.4 s/61 点）
- **有效值读数（v1.3）**：暂态仿真对每个元件维护滑动窗口（τ≈80 ms）的 U/I 有效值与平均功率，选中元件即在面板显示；灯泡亮度与超额定告警改用平均功率，交流下不再闪烁
- **RLC 串联谐振示例（v1.3）**：L=0.1H、C=100μF → f₀=50.33 Hz；谐振时灯最亮、电容电压达电源峰值的约 4.85 倍（过电压），扫频可实测谐振峰
- 配套示例：充放电（充电/放电电流反向）、自感（B 灯先亮 A 灯慢亮、断电续流）、交流 RC（相位滞后）、RLC 谐振（谐振峰+过电压）

### 教学辅助
- 数据表：逐元件 U / I / P（带自动编号 R1/L1/E1…）；变阻器分 A-P、P-B 两段显示
- **实验数据面板（v1.8）**：伏安法采点 → U-I 描点 → 最小二乘拟合，三种模式——伏安特性曲线（灯丝电阻随温度变化）/ 测电阻（过原点拟合 R）/ 测电源电动势和内阻（纵轴截距 = E、斜率 = r）；数据可导出 CSV（含拟合结果）；配套「测电源 E、r」模板
- 诊断：电源短路、断路、灯泡超功率、灵敏电流计超满偏、二极管反向截止、电容隔直流提示
- 内置模板为用户自定义的 7 个模板（自感现象/测电源电动势和内阻/电磁振荡/分压法测电阻/限流法测电阻/基础串联电路/基础并联电路），可在管理模式隐藏/恢复；启动串联示例不进模板库
- 惠斯通电桥可现场演示"调平衡 → 灵敏电流计读零"

### 测量工具（工具栏「测量工具」按钮，4 个标签页）

- **游标卡尺**：10 / 20 / 50 分度可切换（0.1 / 0.05 / 0.02 mm），金属质感外观、主尺/游标尺/外测量爪/紧固螺钉结构标注；拖动游标框自由开合，放入随机物体后输入读数自测，读数不估读；视图可放大至 6 倍（按钮/滚轮，自动跟随读数区，v1.6）
- **螺旋测微器（v1.5 加零误差）**：主尺含半毫米刻度，可动刻度 50 分度，拖动套筒旋进旋出；可随机生成初读数（零误差），测量值 = 末读数 − 初读数；估读到 0.001 mm，答案误差 ≤ 0.002 mm 判对；视图可放大至 6 倍（跟随鼓轮读数线，v1.6）
- **多用电表（v1.5 真实面板）**：参考学生多用表面板——右侧选择开关旋钮（OFF / 直流电压 2.5·10·50V / 直流电流 25·250mA / 欧姆 ×1·×10·×100）点击选档，欧姆调零旋钮可点击，红/黑表笔插孔标注；均匀刻度 + 非线性反向欧姆刻度，换欧姆档需短接调零，欧姆读数 = 标尺读数 × 倍率
- **改装电表**：只画改装后的表（虚线外壳 + 端钮 + G 与 R串/R并，v1.5 移除被测电路）；给定表头（Ig/Rg）自动推导 R串/R并，滑杆输入信号验证线性读数，附不改装烧表警告

### 模板库（工具栏「模板库」按钮）

- 7 个内置模板集中展示，载入后可随意手动修改；管理模式下可**隐藏/恢复**内置模板，「我的模板」单独存放新保存的模板（删除带确认）
- **我的模板**：把当前画布命名保存为个人模板（存 localStorage），随时载入；可**删除**（带确认，防误删）

### 编辑器
- 撤销 / 重做（Ctrl+Z / Ctrl+Y，100 步）、保存 / 加载 JSON、本地恢复
- 视图缩放（按钮 / 滚轮，0.5×–4×）与平移（空白处拖动）
- **编辑器增强（v1.8–v1.13）**：元件旋转 90°（面板按钮 / 快捷键 R，文字保持水平）、复制粘贴（Ctrl+C / Ctrl+V）、自动编号标注（R1/L1/E1…）；拖动 2px 细网格吸附 + 引脚磁性对齐 + **对齐参考虚线**（与其他元件 x/y 对齐时显示粉色虚线贯穿两元件，松手消失）
- **投影模式（v1.8）**：顶栏一键切换教室大屏大字号高对比显示（自动记忆）
- **新手引导（v1.7）**：首次打开自动弹出 6 步高亮操作引导（元件库/画布/面板/工具栏），可跳过；顶栏「新手引导」随时重看
- 后续拓展方向见《功能扩展建议报告.md》

## 使用方法

1. 下载 `电路可视化-演示-v1.13.html`，双击打开即可——**HTML 本身就是完整程序**，拷贝 / 发送这一个文件即可使用，离线可用，无需安装浏览器以外的任何东西（桌面版 exe 已于 v1.9 后停止更新，最后版本冻结于 v1.9；后续新功能只在 HTML 中提供）
2. 从左侧元件库拖元件到画布，点元件引脚拉线到另一引脚连线；
3. 点导线可选中删除；右上角按钮保存 / 加载电路文件；
4. 点「▶ 暂态仿真」进入时间轴模式，观察电容充放电、自感、交流波形（配示波器）；RLC 谐振示例里用示波器「扫频分析」实测幅频曲线。
